# Lunar Lander · Moon Touchdown

Free single-file HTML5 physics game. Pilot your lander onto the moon's lit
pads — limited fuel, real momentum, precision touchdowns. One HTML file,
zero assets.

**Play:** https://shuangyueliao.github.io/lunar-lander/

- Desktop keyboard (←/→ rotate, ↑/W main engine) + mobile touch buttons
- Procedural terrain with 3 landing pads per level (narrower pads pay ×2/×3/×5)
- Landing score = fuel left ×2 + pad multiplier ×500; 5 ships, endless levels
- Camera zooms in as you descend; best score & top level saved locally
- Procedural vector graphics & WebAudio sounds (engine noise, chimes, explosions)

## Submitting to portals

The game is a single self-contained HTML file, ready for HTML5 game portals
(CrazyGames, GameDistribution, itch.io). Fork/clone and submit.
